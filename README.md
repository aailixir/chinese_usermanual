# 第二章: 開始使用
安裝完畢後，請使用瀏覽器並輸入網址如下：
http://127.0.0.1:8080
http://localhost:8080 

您可以輸入預設使用者名稱及密碼：

	使用者名稱：demo@example.com
	密碼：demo

輸入完使用者名稱及密碼後，請點選「登錄」鍵。
